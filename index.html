Learn the Math & Experiments

1. Hydraulic Resistor Network

L(D) · p = b   |   Qij = (Dij / Leff) · (pi − pj)

Each tube acts as a fluid pipe whose conductance is D / Leff. A Jacobi-preconditioned Conjugate Gradient solver finds node pressures satisfying Kirchhoff flow conservation at every junction.

2. Nonlinear Feedback (μ < 1 vs μ > 1)

Dt+1 = (Dt + Δt · |Q|μ / (1 + |Q|μ)) / (1 + Δt)

Semi-implicit integration keeps adaptation stable at large Δt. When μ < 1, small parallel routes survive as a resilient mesh; when μ > 1, positive feedback amplifies trunks and prunes weak detours into trees.

3. Multi-Terminal Tokyo Rail (2010)

I0 = 0.65 √(K / 2)   |   Qrms = √(⟨Q2⟩)

In Tero et al. (Science, 2010), all city hubs are equal food sources explored via random pairs, while bright light masks high-cost barriers like Tokyo Bay so corridors curve naturally around water.

4. Fault Tolerance & Self-Healing

Performance = FT / (TL/MST · MD)

A Minimum Spanning Tree has minimum cost (TL = 1.0) but zero fault tolerance (FT = 0). Physarum balances low cost, short travel distance (MD), and redundant cycles that automatically regrow if a main link is severed.
